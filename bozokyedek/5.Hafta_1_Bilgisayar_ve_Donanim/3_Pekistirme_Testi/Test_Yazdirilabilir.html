B. BÖLÜM: ÇOKTAN SEÇMELİ DEĞERLENDİRME TESTİ (15 Soru) Doğru şıkkı işaretleyiniz
1. Bilgisayarın tüm parçalarını birbirine bağlayan devasa ana devre kartı hangisidir?
A Ekran Kartı
B Anakart
C Ses Kartı
D Ağ Kartı
Doğru Şık: A
2. Bilgisayarın 'beyni' sayılan ve tüm mantıksal hesaplamaları yürüten parça hangisidir?
A RAM Bellek
B Sabit Disk
C İşlemci (CPU)
D Güç Kaynağı
Doğru Şık: A
3. Elektrik kesildiğinde veya bilgisayar kapandığında içindeki tüm verileri sıfırlanan geçici hafıza hangisidir?
A Sabit Disk (HDD)
B SSD
C Flash Bellek
D RAM Bellek
Doğru Şık: A
4. Dosyaları, oyunları ve fotoğrafları yıllarca kalıcı olarak saklayan depolama birimi hangisidir?
A Sabit Disk / SSD
B RAM Bellek
C İşlemci
D Anakart
Doğru Şık: A
5. Aşağıdakilerden hangisi dış dünyadan bilgisayara bilgi aktaran bir GİRİŞ birimidir?
A Monitör
B Klavye
C Hoparlör
D Yazıcı
Doğru Şık: A
6. Aşağıdakilerden hangisi bilgisayarda işlenen bilgileri dışarıya veren bir ÇIKIŞ birimidir?
A Mikrofon
B Fare
C Hoparlör
D Web Kamerası
Doğru Şık: A
7. Görüntü verilerini işleyip monitöre aktaran ve oyunların akıcı görünmesini sağlayan parça hangisidir?
A Ses Kartı
B Ağ Kartı
C Optik Sürücü
D Ekran Kartı (GPU)
Doğru Şık: A
8. 220V şehir elektriğini parçaların kullanacağı düşük voltaja çevirip dağıtan donanım hangisidir?
A Güç Kaynağı (PSU)
B Anakart
C İşlemci
D Sabit Disk
Doğru Şık: A
9. Hem görüntü gösterip hem parmakla komut alabilen çift yönlü donanım hangisidir?
A Kulaklık
B Dokunmatik Ekran
C Projeksiyon
D Tarayıcı
Doğru Şık: A
10. Bilgisayarın kablolu veya kablosuz olarak internete/ağa bağlanmasını sağlayan iç donanım hangisidir?
A Ses Kartı
B Ekran Kartı
C Ağ Kartı (Ethernet)
D RAM
Doğru Şık: A
11. İşlemcinin aşırı ısınıp bilgisayarın kapanmasını veya hasar görmesini engelleyen parça hangisidir?
A Sabit Disk
B Güç Kaynağı
C Kasa Kapağı
D Soğutucu / Fan
Doğru Şık: A
12. Seçili bir metni veya dosyayı KOPYALAMAK için hangi klavye kısayolu kullanılır?
A Ctrl + V
B Ctrl + C
C Ctrl + X
D Ctrl + Z
Doğru Şık: A
13. Kopyalanan veya kesilen bir ögeyi yeni bir yere YAPIŞTIRMAK için hangi kısayol kullanılır?
A Ctrl + S
B Ctrl + C
C Ctrl + V
D Ctrl + A
Doğru Şık: A
14. Klavyede imlecin SAĞINDAKİ harfi veya seçili bir dosyayı silmek için hangi tuşa basılır?
A Delete
B Backspace
C Space
D Enter
Doğru Şık: A
15. Basılı bir fotoğrafı veya kağıttaki yazıyı tarayıp bilgisayara aktaran giriş birimi hangisidir?
A Yazıcı (Printer)
B Hoparlör
C Monitör
D Tarayıcı (Scanner)
Doğru Şık: A
