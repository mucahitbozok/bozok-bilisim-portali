B. BÖLÜM: ÇOKTAN SEÇMELİ DEĞERLENDİRME TESTİ (16 Soru) Doğru şıkkı işaretleyiniz
1. Yapay zekâ aşağıdakilerden hangisini taklit etmeye çalışır?
A Bilgisayarın fiziksel parçalarını
B İnsanların düşünme, öğrenme ve karar verme becerilerini
C İnternet bağlantısını
D Elektrik üretimini
Doğru Şık: B
2. Aşağıdakilerden hangisi yapay zekânın yapabildiği işlemlerden biridir?
A Öğrenme
B Uyuma
C Acıkma
D Üşüme
Doğru Şık: A
3. Aşağıdakilerden hangisi yapay zekâ kullanımına örnektir?
A Kalem açmak
B Deftere yazı yazmak
C Telefonun yüz tanıma özelliği
D Kitap sayfasını çevirmek
Doğru Şık: C
4. YouTube’un izlediğimiz videolara göre yeni videolar önermesi aşağıdakilerden hangisine örnektir?
A Dosya sıkıştırma
B Yazıcı kullanımı
C Klavye kullanımı
D Yapay zekâ ile öneri sistemi
Doğru Şık: D
5. İnsan zekâsı ve yapay zekânın ortak özelliklerinden biri aşağıdakilerden hangisidir?
A İkisinin de öğrenebilmesi
B İkisinin de duygularının olması
C İkisinin de uyuması
D İkisinin de hayal kurması
Doğru Şık: A
6. Aşağıdakilerden hangisi insan zekâsı ile yapay zekâ arasındaki farklardan biridir?
A İkisi de karar verebilir.
B İnsanlar duygulara sahiptir, yapay zekâ sahip değildir.
C İkisi de hata yapabilir.
D İkisi de yeni şeyler keşfedebilir.
Doğru Şık: B
7. İnsan zekâsı nasıl öğrenir?
A Sadece sayılarla
B Kodlarla
C Deneyimle
D Yalnızca internetten
Doğru Şık: C
8. Yapay zekâ nasıl öğrenir?
A Duygularla
B Hayallerle
C Sezgilerle
D Verilerle
Doğru Şık: D
9. İnsanlar karar verirken aşağıdakilerden hangisini kullanabilir?
A Duygular ve bilgi
B Sadece sensörler
C Sadece kod
D Yalnızca rastgele seçim
Doğru Şık: A
10. Aşağıdakilerden hangisi yapay zekânın insana göre daha güçlü olduğu alanlardan biridir?
A Duygu hissetme
B Çok hızlı hesaplama
C Hayal kurma
D Arkadaşlık kurma
Doğru Şık: B

A Hastaneler
B Oyunlar
C Kalem kutuları
D Alışveriş siteleri

A Hastaneler
B Eğitim
C Alışveriş
D Arabalar
Doğru Şık: D

C Sınıf yoklaması
D Müzik dinleme

B Bilgilerin güvenliğine
C Bilgisayar masasının rengine
D Klavyenin büyüklüğüne
